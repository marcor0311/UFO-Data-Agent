# Avance de reproducción

Archivo de trabajo con el código preparado durante la recuperación. Incluye los montajes aislados, las configuraciones de las 17 vistas, la exportación estática y el cotejo con DB Test.

- [Montaje de inspección](_compartido/reproducir.cjs)
- [Exportación de láminas](_compartido/exportar-estatico.py)
- [Cotejo de renderizadores](_compartido/verificar.cjs)

Los 53 archivos del avance conservan el contenido del respaldo. Los enlaces relativos comparten estilos, SDK y módulos con la [biblioteca original](../README.md). Para reutilizar el avance en esta ubicación, indica la ruta a `DB Test` al ejecutar sus herramientas, ya que la ruta predeterminada corresponde a la estructura anterior.
