# Propuestas pendientes

No hay propuestas pendientes: todas las de la biblioteca están implementadas en el Data Agent y viven en [done/](../done/).

Una propuesta nueva entra aquí con su ficha (`README.md` con estado, utilidad, origen, datos, prompt de ejemplo y límites) y se mueve a `done/` cuando el agente la dibuja. Antes de proponerla, comprueba en [docs/preguntas-y-graficos.md](../../docs/preguntas-y-graficos.md) si la pregunta ya tiene gráfico.

## Detalles abiertos de propuestas implementadas

La pregunta de cada una ya tiene gráfico; falta una interacción de la lámina original.

- [formas-reportadas](../done/formas-reportadas/README.md): búsqueda y paginación de la lista de formas.
- [reportes-por-ano](../done/reportes-por-ano/README.md): elegir un año para abrir sus informes ([#48](https://github.com/marcor0311/UFO-Data-Agent/issues/48)).
