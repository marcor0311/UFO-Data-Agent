# Perfiles de duración y K-means

**Estado: Solo idea**

## Concepto

Conservar la idea de agrupar perfiles con duración y número de testigos, usando registros que tengan ambas medidas documentadas.

## Utilidad

Permitir comparar perfiles numéricos y detectar si la selección de variables define patrones que merecen una revisión cualitativa.

## Implementación futura

Requiere medir la intersección válida, decidir una transformación para distribuciones sesgadas, estandarizar unidades y comparar varios valores de K con estabilidad y tamaño de grupos. La selección de tecnología queda pendiente de esa evaluación.

## Prompt de ejemplo

> Explora perfiles de duración y testigos con K-means. Indica el N, los faltantes y cómo cambia la asignación al variar K.

## Límites y pendientes

Los resultados dependen de las variables, la escala y la inicialización. Un grupo numérico no clasifica autenticidad ni origen.
