# Prototipo del globo

Captura del prototipo animado que dio origen a la vista `globe` ([done/globo-3d](../done/globo-3d/README.md)). El resto de prototipos animados se descartó porque no encajaba en el proyecto.

Para ver el prototipo en vivo, desde `propuesta-graficos/`:

```sh
python3 -m http.server 8765
```

y abre `http://127.0.0.1:8765/prototipos-animados/06-globo.html`.
